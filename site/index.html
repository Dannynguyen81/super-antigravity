Vì sao cần SUPER-ANTIGRAVITY?

Bảy điểm nghẽn thường gặp, mỗi điểm một giải pháp tích hợp sẵn.

Bộ máy tự học

Tự bắt lỗi, đúc kết bài học qua lệnh /learn và lưu vào .agents/rules/ để dùng lại vĩnh viễn.

Không để trống mã

Bắt buộc viết mã đầy đủ, ngắt an toàn khi chạm ngưỡng token thay vì cắt xén.

Nén ngữ cảnh chiến lược

Chủ động nén bộ nhớ phiên và đọc cây cú pháp AST để chỉ đọc đúng mã cần sửa.

Quy trình 5 cổng chất lượng

spec, plan-review, implementation, qa, ship và handoff, không báo xong khi chưa kiểm thử.

Bộ ba thẩm mỹ chống slop

impeccable, design-taste-frontend và ui-ux-pro-max giữ giao diện ở chuẩn thương mại cao cấp.

Vòng đời tri thức SecondBrain

Sáu tầng quản trị tri thức, tương thích hoàn toàn với Obsidian Graph View.

Khóa phạm vi trước khi code

Phỏng vấn trắc nghiệm 2-3 câu then chốt để chốt yêu cầu rồi mới bắt tay làm.

Kiến trúc hệ thống

Tài liệu đi qua các tầng từ thô tới thành phẩm.

  1. 10-inbox/Phễu tiếp nhận tài liệu thô, ghi chú nhanh
  2. 20-sources/Nguồn tham khảo gốc, tài liệu bóc tách từ inbox
  3. 30-working/Không gian làm việc, checklist ca, biên bản
  4. 40-knowledge/Chân lý cốt lõi: SOP, Runbook
  5. 50-outputs/Thành phẩm phát hành: báo cáo, công văn
  6. 90-archive/Lưu trữ lịch sử các giai đoạn trước

Cài đặt một chạm

Cách 1: dùng trực tiếp làm workspace (khuyến nghị)

  1. Clone repo về máy. 
    git clone https://github.com/dannynguyen81/super-antigravity.git
cd super-antigravity
  2. Mở thư mục bằng Google Antigravity IDE, Cursor hoặc VS Code.
  3. Mở bằng Obsidian (Open folder as vault) để xem đồ thị tri thức.
  4. Chạy script thiết lập trên Windows. 
    .\scripts\setup-windows.ps1

Cách 2: cài plugin toàn cục vào Antigravity

Dùng đủ 9 plugin cho mọi dự án trên máy.

.\scripts\install-plugins-global.ps1

Ra lệnh bằng ngôn ngữ tự nhiên

Cứ nói tự nhiên, hệ thống tự kích hoạt đúng mô-đun.

  • Lập đặc tả tính năng mới spec
  • Tra cứu quy trình tiếp nhận yêu cầu và SLA tra-cuu-sop
  • Soạn biên bản cuộc họp giao ban sáng nay soan-bien-ban-hop
  • Tìm bug và kiểm thử giao diện qa
  • Vẽ sơ đồ kiến trúc hệ thống chuẩn SVG baoyu-diagram
  • Deploy worker lên Cloudflare cloudflare-suite
