# 📚 20 - Nguồn Tài Liệu Tham Khảo (Sources)

Thư mục lưu trữ các tài liệu gốc, nguồn dữ liệu bên ngoài, sách, bài viết nghiên cứu, tài liệu từ đối tác, hoặc các file trích xuất được giữ nguyên vẹn để làm bằng chứng tham khảo.

## 📌 Nguyên Tắc Hoạt Động
1. **Tính bất biến (Immutability)**: Tài liệu nguồn phải phản ánh trung thực thông tin từ bên ngoài; hạn chế sửa đổi nội dung nguyên bản.
2. **Trích dẫn minh bạch**: Mọi khẳng định, quy trình hay báo cáo nội bộ khi dựa vào tài liệu nguồn cần trích dẫn liên kết dạng `[[20-sources/ten-file|Nguồn]]`.
3. **Phân loại**:
   - `sach-tai-lieu/`: Sách chuyên khảo, cẩm nang ngành.
   - `tai-lieu-doi-tac/`: Hợp đồng, tài liệu kỹ thuật từ nhà cung cấp/đối tác.
   - `trich-xuat-inbox/`: Các file được chuyển đổi từ file nhị phân trong Inbox.
